## Project Overview

DreamDrive SA is a fictional car rental organisation created for this website project.

The website provides information about the organisation, available vehicles, rental services and contact details.

The website is designed to give customers an easy way to view vehicles and make rental enquiries.

---

## Website Goals and Objectives

The main goal of the DreamDrive SA website is to provide customers with clear information about the car rental organisation.

The objectives are to:

- Provide information about DreamDrive SA.
- Display available rental vehicles.
- Explain the services offered.
- Allow customers to make rental enquiries.
- Provide contact information and branch locations.
- Create a simple and easy-to-use website.

---

## Key Features and Functionality

The website includes the following features:

- Home page
- About Us page
- Vehicles page
- Services page
- Enquiry page
- Contact page
- Navigation menu
- Vehicle information
- Rental enquiry form
- Contact form
- Branch location information
- Images
- Basic JavaScript functionality
- Responsive CSS styling

---

## Website Pages

### Home

The Home page introduces DreamDrive SA and provides links to the main sections of the website.

### About

The About page provides information about the organisation, history, mission, vision and target customers.

### Vehicles

The Vehicles page displays different rental vehicles and provides information such as price, seating capacity, transmission and fuel type.

### Services

The Services page explains the different rental services offered by DreamDrive SA.

### Enquiry

The Enquiry page allows customers to provide their details and rental requirements.

### Contact

The Contact page provides contact information, branch locations and a contact form.
