## Project Overview

DreamDrive SA is a fictional car rental organisation created for this website project.

The website provides information about the organisation, its rental vehicles, services and contact details.

The website aims to make it easier for customers to explore available vehicles, check vehicle availability and proceed with rental bookings.

## Website Goals and Objectives

The main goal of the DreamDrive SA website is to provide customers with clear information and a convenient way to explore car rental services.

The objectives are to:

- Provide information about DreamDrive SA.
- Display the vehicles available for rental.
- Allow customers to check vehicle availability.
- Allow customers to select a vehicle and enter rental dates.
- Provide a booking and checkout process.
- Explain the services offered.
- Allow customers to make general enquiries.
- Provide contact information and branch details.
- Create a simple and user-friendly website.

## Website Pages

### Home

The Home page introduces DreamDrive SA and provides links to the main sections of the website.

### About

The About page provides information about the organisation, including its history, mission, vision and target customers.

### Vehicles

The Vehicles page displays different rental vehicles and provides information such as price, seating capacity, transmission and fuel type.

### Services

The Services page explains the different rental services offered by DreamDrive SA.

### Enquiry

The Enquiry page allows customers to provide their details and rental requirements.

### Contact

The Contact page provides contact information, branch details and a contact form for general messages.

## Vehicle Availability and Checkout

DreamDrive SA aims to provide customers with a convenient vehicle booking experience.

The planned availability feature will allow customers to select a vehicle and enter their collection and return dates. JavaScript will be used to check the demonstration availability information and display an appropriate result.

Customers will then be able to proceed to the booking or checkout stage.

Note: Availability will be based on the demonstration data implemented in the project. It will not represent live vehicle inventory unless a booking database or external system is connected.
